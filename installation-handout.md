# QDK Installation Guide

Get set up before the session so you're ready to go.

---

## 1. Install Visual Studio Code

Download and install from: https://aka.ms/vscode

---

## 2. Install the Quantum Development Kit Extension

1. Open VS Code.
2. Open the Extensions view (Ctrl+Shift+X / Cmd+Shift+X).
3. Search for **"Quantum Development Kit"** by Microsoft DevLabs.
   - Look for the blue checkmark next to **microsoft.com**.
4. Click **Install**.

---

## 3. Sign in with GitHub for GitHub Copilot Chat

1. Click the account icon in the bottom-left of VS Code.
2. Sign in with your GitHub account (or create one at https://github.com/).

---

## 4. Verify Your Setup

1. Look for the Microsoft Quantum Möbius strip logo in the Activity Bar (the icon strip on the left side of VS Code).
2. Open Copilot Chat (Ctrl+Alt+I / Cmd+Alt+I) to chat with GitHub Copilot.

If you see both, you're all set!
